# 已知限制与未完成项

本页描述当前仓库的真实边界。列表中的“计划”不是已交付能力。

## 当前发布阻塞项

- 本地 Codex 内置 Chromium 已完成 v86 启动和串口双向交互探针，但精确浏览器版本尚未登记，尚未形成跨浏览器矩阵；
- 尚未在 Vercel Preview 上验证真实来宾启动；
- 当前远程探针是 Linux 5.6.15 i686/BusyBox；BusyBox Tab、`↑` 历史、Ctrl+C 和退出码已有本地证据，但未证明 Bash、Readline 和 bash-completion 可用；
- `printf` 健康挑战和 `false` 退出码已验证，管道、重定向、完整方向键集和终端 resize 仍缺单独证据；
- IndexedDB 快照已通过一次保存/关闭/恢复并保留文件，并绑定完整虚拟机配置指纹；但尚无循环、崩溃恢复、配额不足和版本迁移证据；
- 探针内核已登记大小和 SHA-256，且前端会校验；仍缺可重复构建配置、SBOM 和完整许可证/源码材料，不能作为生产镜像分发；
- 命令文档目前是人工起步内容，不代表覆盖来宾中全部已安装命令；
- 依赖真实来宾的小型固定 e2e 镜像尚未进入 CI。

## “真实 Linux”与硬件边界

当前技术探针不是伪命令解释器：健康挑战、`uname -m` 和退出码来自 v86 模拟的 x86 CPU 上运行的真实 Linux 5.6.15/BusyBox。不过“真实 Linux 来宾”不等于“正式 Bash 环境”，也不等于“真实嵌入式开发板”。

当前/计划中的 x86 来宾适合验证 Shell、文件系统、进程、权限、BusyBox、ELF 工具和交叉编译概念。它不能真实提供：

- ARM/RISC-V 指令集开发板行为；
- GPIO、I²C、SPI、UART 外设接线；
- NAND/MTD 磨损、坏块和真实闪存时序；
- 特定 SoC 启动 ROM、U-Boot 板级配置和设备驱动；
- 实机功耗、时序和性能数据。

相关课程必须标记为“真实来宾实验”“概念演示”或“需要硬件”，不能生成伪造硬件输出。

## 安装流程边界

V1 的安装页用于讲解并生成预置配置，目标行为是复制一个经过校验的基础镜像、写入安全的用户配置并执行首次启动初始化。它不是从 ISO 运行安装器，也不支持联网选择任意发行版和软件包。

当前本地浏览器已走通六步安装，并验证配置状态联动到来宾健康检查后的 `ready`。这只证明前端安装状态机和实验室联动；把用户名、hostname、时区等安全注入正式来宾的完整链路仍需验证。

## 持久化和浏览器存储

当前原型使用 IndexedDB 保存安装状态和单份 v86 状态。单次“创建文件 -> 保存 -> 关闭 -> 恢复 -> 文件存在”已经通过。尚未实现或验收：

- 两代快照和损坏回退；
- 自动保存、命名检查点、备份导入/导出；
- 多标签页单写锁；
- 存储持久化授权和配额预警的完整交互；
- 清理数据前的容量明细；
- 不同 v86、镜像或内存配置间的兼容迁移。

浏览器可能因为无痕模式、用户清理、空间压力或策略限制删除站点数据。本地状态不会自动跨设备同步。静态 Vercel 部署没有云端磁盘或账号后端。

## 网络限制

V1 默认不向来宾提供任意公网 TCP。网络命令可以存在，但在离线来宾中应返回真实失败；网站不能替换成“成功”演示。未来增加联网需要受控中继、滥用防护、隐私审查和成本评估，不属于当前零后端范围。

启动探针本身仍需从外部静态来源下载 v86/BIOS/内核。内核经本地 Vite proxy 或拟议的 Vercel external rewrite 以同源路径获取，前端校验 5,166,352-byte 大小和 SHA-256。网络错误、代理行为变化或第三方资源不可用仍会导致启动失败；哈希和代理也不等于取得再分发许可。正式发布应使用不可变、经过哈希和许可审核的资产方案。

## 浏览器与性能

目前只在 Codex 内置 Chromium 完成一轮本地验证，精确 Chromium 版本尚未记录，因此没有可声明的兼容浏览器矩阵。390×844 视口无页面横向溢出只证明单一响应式布局检查；移动真机、低内存设备、Safari/Firefox 以及隐私增强模式均未完成验收。

配置 64 MiB 来宾内存并不代表页面只占 64 MiB。WASM、模拟器状态、终端滚动缓冲、下载缓存和保存时的状态副本都会增加占用；真实峰值和启动时间仍待测量。浏览器标签页在运行虚拟机后会明显重于普通静态网站。

## 内容覆盖

Linux 没有封闭的“所有命令”集合。正式可验收口径是：网站索引覆盖固定来宾镜像中 Bash 关键字/内建、函数、别名、BusyBox applet 和 `$PATH` 可执行文件的 100%。

当前尚未生成正式 `command-manifest.json`，也没有软件包来源、版本、man/help 入口和覆盖率 CI。现有中文命令说明只能称为起步集合。

## 免费部署边界

GitHub + Vercel 可以在个人学习、流量较低且符合免费计划条款时实现零现金成本，但免费额度、可接受用途和限制会变化。Vercel Preview 尚未部署/验证，当前 external rewrite 也没有生产许可结论；技术探针禁止 Production。本项目不提供云端虚拟机、WebSocket TCP 中继或云端持久化。

每次发布前都应重新检查服务条款和用量。不能把“当前目标为零付费”表述为永久免费或无限使用保证。
