# 命令行滚动居中设计

## 目标

在 Lab 页面向下滚动时，让命令行卡片在桌面端和平板端持续停留在视口中部附近，避免课程列表或学习提示变长后终端被推到页面上方。同时保持终端实例、命令历史、当前输入和 Tab 补全状态不变。

## 交互规则

- 当视口宽度大于 `820px` 时，命令行卡片使用 CSS 吸附定位。
- 吸附位置优先按命令行卡片的 `590px` 基准高度计算，使其接近视口垂直中部。
- 当视口高度不足时，吸附位置至少保留 `88px` 顶部空间，避免被 `72px` 高的固定导航栏遮挡。
- 当视口宽度不大于 `820px` 时，命令行恢复普通文档流，不进行吸附，避免遮挡手机上的课程提示。
- 左侧课程栏和右侧提示栏继续正常参与页面滚动。

## 实现方式

只修改 Lab 页相关 CSS：

1. 将 `.lab-layout` 的交叉轴对齐从拉伸改为顶部对齐，避免命令行卡片被最高侧栏拉长。
2. 为 `.terminal-card` 增加 `position: sticky`、`align-self: start` 和基于视口高度的 `top`。
3. 在现有 `max-width: 820px` 媒体查询中把 `.terminal-card` 恢复为 `position: static`。

不增加滚动事件监听，不改变 React 组件层级，也不重新挂载 xterm 或模拟终端。

## 验收标准

- 桌面视口中，向下滚动 Lab 页面后，命令行卡片仍完全可见并位于视口中部附近。
- 命令行顶部不会被导航栏覆盖。
- 课程与提示内容仍可正常滚动和点击。
- 手机视口中，命令行保持普通文档流并且页面无横向溢出。
- 现有命令执行、命令填入、Tab 补全和课程切换测试继续通过。

## 测试策略

- 先添加一个 Playwright 测试，在足够高的桌面视口中记录终端位置、滚动页面，并断言终端仍在视口内且中心点接近视口中心。
- 添加手机视口断言，确认终端的计算定位为 `static`。
- 运行完整端到端测试、单元测试、类型检查、lint 和生产构建。
